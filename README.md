# Unlocking Societal Trends in Aadhaar Enrolment and Updates

### UIDAI Data Hackathon 2026

An exploratory data analysis project focused on identifying demographic and geographical patterns in Aadhaar enrolment and demographic updates using data analysis and geospatial visualization techniques.

---

## Project Overview

Aadhaar data provides valuable insights into demographic patterns and regional trends across India. This project explores Aadhaar enrolment and demographic update datasets to understand variations across states, age groups, and geographical regions.

The project uses Python-based data analysis and visualization techniques to examine large datasets, identify patterns, perform data cleaning, and generate geographical visualizations.

## Objectives

- Analyze Aadhaar enrolment and demographic update patterns.
- Explore state-wise and district-wise variations.
- Examine demographic trends across different age groups.
- Perform data cleaning, preprocessing, and duplicate analysis.
- Visualize geographical distributions across India.
- Generate district-level geographical insights for Maharashtra.

## Key Analysis Areas

### 1. Data Preprocessing
- Loading and merging multiple CSV data files.
- Handling missing and duplicate records.
- Data cleaning and transformation.
- Preparing datasets for further analysis.

### 2. Demographic Analysis
- State-wise data exploration.
- Age-group distribution analysis.
- Identification of regional variations.
- Examination of demographic trends.

### 3. Geospatial Analysis
- Geographical visualization of state-level patterns across India.
- District-level analysis of Maharashtra.
- Choropleth mapping using geographical shapefiles.
- Visualization of regional variations.

## Getting Started

### Prerequisites

Install Python 3.9 or later and Jupyter Notebook.

### 1. Clone the Repository

```bash
git clone https://github.com/aanchalkalambe/UIDAI-Data-Hackathon-2026.git
```

### 2. Navigate to the Project Directory

```bash
cd UIDAI-Data-Hackathon-2026
```

### 3. Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn geopandas jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the relevant notebook and execute the cells in sequence.

## Dataset Requirements

The analysis depends on the corresponding Aadhaar CSV datasets and geographical shapefiles.

- Keep the required CSV files in their expected project directories.
- Ensure all parts of a shapefile dataset (`.shp`, `.shx`, `.dbf`, `.prj`, etc.) are available together.
- Update file paths according to your local environment before executing the notebooks.

**Note:** The notebooks may require modifications to file paths when executed on a different system.
